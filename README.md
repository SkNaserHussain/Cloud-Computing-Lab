# Cloud Computing Lab

This repository contains the laboratory work, practical implementations, and reports completed as part of the Cloud Computing course.

## Experiments

### Experiment 1 – Installation of Hypervisor and Virtual Machine

- Installed Oracle VirtualBox as the hypervisor.
- Created and configured an Ubuntu virtual machine.
- Configured CPU, RAM, storage, and network settings.
- Installed Ubuntu Desktop using an ISO image.
- Installed required build tools and Linux kernel headers.
- Verified the working of the virtual machine.

**Report:** `Lab1_Report.pdf`

### Experiment 2 – TCP Client-Server Communication

- Created two Ubuntu virtual machines using VirtualBox.
- Configured an internal network between the virtual machines.
- Assigned static IP addresses.
- Implemented TCP client-server communication using Python sockets.
- Tested two-way message communication between the client and server.

**Report:** `Lab2_Report.pdf`
